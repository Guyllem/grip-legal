# grip-legal

Documents légaux de l'application **GRIP** (réseau social streetworkout / callisthénie),
publiés via GitHub Pages.

- [Politique de confidentialité](https://guyllem.github.io/grip-legal/confidentialite.html)

Le code de l'application vit dans un dépôt privé distinct. **Ce dépôt ne contient que des
documents légaux** : son historique est public et le reste définitivement.

Ces documents décrivent les traitements **réellement effectués** par la version courante de
l'application, jamais ceux qui sont prévus. Toute évolution d'un traitement doit être
répercutée ici *avant* sa mise en service.
